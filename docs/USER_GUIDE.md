# વ્રજ ખેતી હિસાબ — ઉપયોગ માર્ગદર્શિકા (User guide)

આ માર્ગદર્શિકા એપ વાપરનાર માટે છે. દરેક વિભાગમાં પહેલાં "શું કરવું" અને પછી "ધ્યાન રાખો" લખેલું છે.

---

## 1. એપ ઇન્સ્ટોલ કરવી (Install)

1. ફોનમાં આ લિંક ખોલો: https://github.com/solerunner26/Vrajfarm/releases/latest
2. `VrajKhetiHisab-….apk` ફાઇલ દબાવીને ડાઉનલોડ કરો.
3. ડાઉનલોડ પૂરું થાય એટલે ફાઇલ ખોલો. ફોન "આ સ્રોતથી મંજૂરી આપો" પૂછે તો ચાલુ કરો, પછી **Install** દબાવો.
4. એપ ખોલો અને 4 અંકનો PIN બનાવો (બે વાર એ જ PIN).

**ધ્યાન રાખો:** જૂની `0.1.0 beta` આવૃત્તિ હોય તો પહેલાં તેને Uninstall કરો. એ બીજી સહી (signature) થી બનેલી હતી, એટલે તેના ઉપર નવી આવૃત્તિ ચડતી નથી.

## 2. અપડેટ (Update)

- નવું અપડેટ આવે ત્યારે એપ ખોલતાં જ **"નવું અપડેટ આવ્યું છે"** દેખાશે. **"હમણાં અપડેટ કરો"** દબાવો — બાકીનું એપ કરશે.
- પહેલી વાર ફોન "આ સ્રોતથી મંજૂરી આપો" માંગશે; ચાલુ કરીને પાછા આવો, ડાઉનલોડ આપોઆપ ચાલુ થશે.
- દિવસમાં બે વાર એપ પાછળથી પણ તપાસે છે અને સૂચના (notification) મોકલે છે.
- જાતે તપાસવા: **સેટિંગ › એપ અપડેટ**.

## 3. હોમ સ્ક્રીન (Home)

| ભાગ | શું છે |
|---|---|
| ઉપર તારીખ | દબાવતાં પંચાંગ કેલેન્ડર ખુલે |
| બેકઅપ બટન | આજે બેકઅપ ન લીધો હોય તો લાલ "!" સાથે; દબાવતાં બેકઅપ ખુલે |
| હિસાબ | કુલ નફો-નુકસાન, ખેતર, પશુપાલન, અંગત |
| ટાઇલ | ભાગિયા ઉપાડ, અંગત / ઘર, સામાન્ય ખર્ચ, ખરીદી, મિલકત વ્યવસ્થા, દૂધ રજીસ્ટર |
| નીચે બટન | **− ખર્ચ / ઉપાડ** અને **+ આવક / વેચાણ** |

**રકમ છુપી રાખવી:** હોમ પરની બધી રકમ `₹XXXXX.XX` દેખાય છે. **આંખ** નું બટન દબાવતાં બધી રકમ દેખાય; ફરી દબાવતાં છુપાઈ જાય. હંમેશાં દેખાડવી હોય તો **સેટિંગ › સામાન્ય સેટિંગ › "હોમ પર રકમ હંમેશાં બતાવો"**.

## 4. એન્ટ્રી કરવી (Entry) — 3 ટેપ

1. **આવક / વેચાણ** કે **ખર્ચ / ઉપાડ** પસંદ કરો.
2. **ટેપ 1 · વિભાગ:** ખેતર, પશુપાલન, ભાગિયા, સામાન્ય કે અંગત.
3. **ટેપ 2:** ખેતર નંબર, ભાગિયા, કે પ્રકાર. નવો પ્રકાર જોઈએ તો **"+ નવો પ્રકાર"** — ત્યાં જ ઉમેરાઈ જાય.
4. રકમ લખો. પાક વેચાણમાં **મણ ગણક**: મણ, વધારાના કિલો અને મણનો ભાવ (20 કિલો = 1 મણ).
5. **ટેપ 3 · ચુકવણી:** "આપી દીધા / મળી ગયા" કે **ઉધાર** માટે "હજી આપવાના / હજી લેવાના" (નામ લખવું જરૂરી).
6. જરૂર હોય તો **નોંધ** (લખો અથવા ઉપરના માઇકથી બોલો) અને **પાવતી ફોટો**.
7. **સાચવો** — "સાચવ્યું ✓" દેખાશે.

**બોલીને આખી એન્ટ્રી:** ઉપરનું માઇક દબાવીને બોલો, જેમ કે "ખાતર બે હજાર ખેતર ત્રણ ઉધાર રમેશભાઈ". એપ બધું ભરી દેશે; તપાસીને **સાચવો** દબાવો.

**સુધારો / કાઢી નાખો:** કોઈ પણ યાદીમાં એન્ટ્રી પર ટેપ કરો → **સુધારો** કે **કાઢી નાખો**. ભૂલથી કાઢી નાખી હોય તો નીચે **"પાછું લાવો"** દબાવો.

## 5. ઉધાર (Credit)

- દુકાનેથી ખાતર ઉધાર લીધું → ખર્ચ, **"હજી આપવાના"**, દુકાનનું નામ.
- વેપારીને માલ વેચ્યો, પૈસા પછી → આવક, **"હજી લેવાના"**, વેપારીનું નામ.
- હોમ પર **"ઉધાર બાકી"** કાર્ડ: "મારે આપવાના" અને "મારે લેવાના" કુલ.
- પૈસા ચૂકવાય ત્યારે કાર્ડ દબાવો → એન્ટ્રી નીચે **ચૂકતે**.
- નફો-નુકસાન એન્ટ્રીની તારીખે જ ગણાય છે; "ચૂકતે" ફક્ત બાકીની યાદીમાંથી કાઢે છે.

## 6. ભાગિયા (Farm managers)

- નામ, મોબાઇલ અને ફોટો: **સેટિંગ › સામાન્ય સેટિંગ › માલિક અને ભાગિયા**.
- ખેતર સોંપવા: ભાગિયાના **સુધારો** માં ખેતર પસંદ કરો. મોટું ખેતર બંને ભાગિયાને સાથે આપી શકાય — બંનેમાં એ ખેતર પસંદ કરો (અથવા ખેતરના સેટિંગમાં "બંને ભાગિયા").
- ઉપાડ: હોમ › **ભાગિયા ઉપાડ**. ઉપાડની એન્ટ્રી પર ટેપ કરી **WhatsApp પાવતી મોકલો** — મેસેજ તૈયાર ખુલે છે, ફક્ત મોકલો દબાવો.

## 7. પશુપાલન અને દૂધ રજીસ્ટર (Milk register)

1. હોમ › **દૂધ રજીસ્ટર** › **દૂધ નોંધો**.
2. તારીખ, સવાર / સાંજ, પશુનું નામ (લખો કે પહેલાનું પસંદ કરો), લિટર, ફેટ %, ભાવ ₹ / લિટર.
3. મહિનાનો સરવાળો: કુલ લિટર, **ડેરીએ આપવાના**, **ડેરીએ આપ્યા**, અને **ફરક**.
4. ડેરીના પૈસા મળે ત્યારે **ડેરી ચુકવણી નોંધો** (પશુપાલન આવક › દૂધ વેચાણ).

## 8. મિલકત અને ઉછીની (Assets)

1. **સેટિંગ › મિલકત વ્યવસ્થા** (અથવા હોમની ટાઇલ) › **"+ નવી મિલકત ઉમેરો"** — શરૂઆતમાં બધી મિલકત એક વાર ઉમેરી દો.
2. મિલકત પર ટેપ કરતાં **સુધારો**, **કાઢી નાખો** કે **ઉછીની આપો**.
3. કોઈ મિલકત માંગે ત્યારે **ઉછીની આપો**: ફોટો, નામ (લખો કે પહેલાનું પસંદ કરો), યાદીમાંથી મિલકત (નવી હોય તો "+ નવી"), આપ્યાની તારીખ અને "કેટલા દિવસ પછી પરત?".
4. **સાચવો + મોકલો** WhatsApp મેસેજ તૈયાર ખોલે છે.
5. એક અઠવાડિયે (કે પરત તારીખે) સૂચના આવે: **પરત આવી ગયું**, **1 અઠવાડિયા પછી** કે **1 મહિના પછી**.

## 9. પંચાંગ કેલેન્ડર

- લીલી તારીખ = એ દિવસે આવક, લાલ તારીખ = ખર્ચ.
- તારીખ દબાવતાં તિથિ, સૂર્યોદય-સૂર્યાસ્ત, એ દિવસની એન્ટ્રી, અને "+ આવક / + ખર્ચ".
- સૂચના ચાલુ/બંધ: **સેટિંગ › પંચાંગ સૂચના**. સલાહ "માન્યતા પ્રમાણે" છે અને બદલી શકાય છે.

## 10. રિપોર્ટ (PDF)

**સેટિંગ › PDF રિપોર્ટ** › રિપોર્ટ પસંદ કરો › સમયગાળો (ડ્રોપડાઉન) કે શરૂઆત/છેલ્લી તારીખ › **PDF બનાવો**. દરેક રિપોર્ટ પર લેટરહેડ: લોગો, નામ, સરનામું, મોબાઇલ, તારીખ.

## 11. બેકઅપ અને પાછું લાવવું (Backup & restore)

**બેકઅપ ક્યાં:** **સેટિંગ › બેકઅપ**

| રીત | કેવી રીતે |
|---|---|
| ગૂગલ ડ્રાઇવ (આપોઆપ) | એક જ વાર **Drive પસંદ કરો** અને ફાઇલ સાચવો. પછી દરરોજ રાત્રે 11:45 એ આપોઆપ. |
| વોટ્સએપ | **WhatsApp પર મોકલો** → પોતાની ચેટ ("You") પસંદ કરી મોકલો. |
| ઈ-મેલ (એક બટન) | એક વાર Gmail સરનામું અને **App Password** લખો (નીચે જુઓ). પછી **ઈમેલ મોકલો** દબાવતાં જ જાય. "દરરોજ રાત્રે ઈમેલ" ચાલુ કરી શકાય. |

**Gmail App Password:** Google ખાતું › સુરક્ષા › 2-Step Verification ચાલુ કરો › **App passwords** › નામ "Vraj Kheti" › જે 16 અક્ષર મળે તે એપમાં લખો. (સાદો Gmail પાસવર્ડ નહીં ચાલે.)

**રોજ યાદ:** આજે બેકઅપ ન લીધો હોય તો હોમ પર લાલ "!" અને રાત્રે 9:30 એ સૂચના.

**નવા ફોનમાં પાછું લાવવું:**
1. નવા ફોનમાં એપ ઇન્સ્ટોલ કરી PIN બનાવો.
2. **સેટિંગ › બેકઅપ › બેકઅપ ફાઇલ પસંદ કરો** → Drive, WhatsApp, Downloads કે Gmail માંથી `VrajKheti-backup…json`.
   (અથવા WhatsApp માં એ ફાઇલ દબાવીને "વ્રજ ખેતી" થી ખોલો.)
3. તારીખ અને એન્ટ્રી સંખ્યા તપાસી **"હા, પાછો લાવો"** — એપ ફરી ખુલશે.

**ધ્યાન રાખો:** બેકઅપ ફાઇલમાં આખો હિસાબ હોય છે; ફક્ત પોતાની ચેટ, પોતાના Drive કે પોતાના ઈ-મેલ પર જ મોકલો. PIN બેકઅપમાં નથી.

## 13. મુશ્કેલી હોય તો (Troubleshooting)

| મુશ્કેલી | ઉપાય |
|---|---|
| અપડેટ નથી દેખાતું | સેટિંગ › એપ અપડેટ દબાવો. ટાઇલ જ ન હોય તો જૂની beta છે: Uninstall કરી નવી APK ઇન્સ્ટોલ કરો. |
| ગુજરાતી કીબોર્ડ નથી ખૂલતું | ફોનના સેટિંગ › ભાષા અને ઇનપુટ › Gboard › ભાષાઓ › ગુજરાતી ઉમેરો. |
| ઈમેલ નથી જતો | App Password 16 અક્ષરનો હોવો જોઈએ, અને 2-Step Verification ચાલુ હોવું જોઈએ. |
| Drive માં નથી સચવાતું | બેકઅપમાં "Drive ફાઇલ બદલો" દબાવી ફરી પસંદ કરો. |
| PIN ભૂલી ગયા | એપનો ડેટા સાફ કરી, બેકઅપમાંથી પાછું લાવવું પડે. |
